## ما في المستودع

| المسار | الوحدة | التشغيل |
|---|---|---|
| `index.html` | صفحة الدخول ثنائية اللغة التي تربط الوحدتين | أيّ متصفّح |
| `financial-sim/` | **المحاكاة التفاعلية**: خريطة بلدة، بطاقة وضع مالي عشوائية، 8 سيناريوهات و66 خياراً، أوسمة ولوحة متصدّرين وتقرير ختامي | بالنقر المزدوج مباشرةً، بلا خادم |
| `financial-town-3d/` | **لعبة العالم المفتوح 3D**: شهر كامل في بلدة عربية ثلاثية الأبعاد بمؤسسات تُدخَل فعلياً، تسوّق بميزانية، تنقّل مربوط بالميزانية، أحداث عشوائية ودورة شهرية | تحتاج خادماً محلّياً (وحدات ES) |
| `vercel.json` | إعداد النشر على Vercel للمسارات الثلاثة | — |

لكلّ وحدة ملف `README.md` خاصّ بها يشرح المضمون التربوي والبنية الهندسية والتحكّم.

## التشغيل محلّياً

```bash
# من جذر المستودع — يخدم الصفحة الرئيسية والوحدتين معاً
python3 -m http.server 8000
# ثم افتح: http://localhost:8000/
```

المحاكاة التفاعلية وحدها تعمل أيضاً بفتح `financial-sim/index.html` مباشرةً من القرص.
اللعبة ثلاثية الأبعاد تحتاج خادماً لأنّها مبنية بوحدات ES، ومكتبة Three.js مثبَّتة محلّياً في `financial-town-3d/vendor/` فلا تحتاج اتّصالاً بالإنترنت.

## النشر

المستودع جاهز للنشر على Vercel كما هو: الصفحة الرئيسية على `/`، والمحاكاة على `/financial-sim/`، واللعبة على `/financial-town-3d/`.

## الإطار التربوي

كلتا الوحدتين متوافقتان مع إطار OECD/PISA للتربية المالية ومتطلّبات وزارة المعارف، وتغطّيان أربع وحدات أساسية: الراتب وقسيمة الراتب، إدارة القروض والائتمان وتجنّب المينوس، مواجهة التضخّم والمدخّرات، والتصدّي للاحتيال الرقمي — مع بُعد اجتماعي خاصّ بواقع البلدة العربية.
